What is this application?

Furniture Order Manager is an e-commerce application used by sales staff to enter and check customer orders for a furniture store.

Roger Pareja - DAW2 PJ6

How to use it

Log in: enter your user name and password. If they are not valid you will see an error message and return to the start page.

Operations menu: choose an operation in the list and press the button to open it.

Create a new order: fill in the order code and the customer data, tick the products the customer wants and enter the quantity of each one. When you send the form, the total price with 21% VAT is shown.

View orders: you can see a table with all the orders, or look for one single order by typing its order code.
