<h1>Documentation</h1>

    <h2>What is this application?</h2>
    <p>Furniture Order Manager is an e-commerce application used by sales staff to enter and check customer orders for a furniture store.</p>
    <h3>Roger Pareja - DAW2 PJ6</h3>

    <h2>How to use it</h2>
    <p><strong>Log in:</strong> enter your user name and password. If they are not valid you will see an error message and return to the start page.</p>
    <p><strong>Operations menu:</strong> choose an operation in the list and press the button to open it.</p>
    <p><strong>Create a new order:</strong> fill in the order code and the customer data, tick the products the customer wants and enter the quantity of each one. When you send the form, the total price with 21% VAT is shown.</p>
    <p><strong>View orders:</strong> you can see a table with all the orders, or look for one single order by typing its order code.</p>
